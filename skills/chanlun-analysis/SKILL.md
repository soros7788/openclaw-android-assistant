# 缠论分析

缠论（Chan Theory）技术分析工作流，用于股票、期货等标的的多级别联动分析。

## 一、明确任务

1. 确认标的：{股票代码/合约代码}
2. 确认分析目标：{看趋势 / 找买点 / 找卖点 / 做交易计划 / 做多级别联动判断}
3. 确认分析周期：{日线 / 30分钟 / 5分钟 / 1分钟}
4. 确认时间范围：{近N天 / 近N周 / 指定起止时间}

## 二、收集行情

1. 收集足够的K线数据，避免样本过短
2. 优先按高周期到低周期准备数据：
   - 高级别：{如日线}
   - 中级别：{如30分钟}
   - 执行级别：{如5分钟}
   - 精细级别：{如1分钟}

## 三、先看高周期

1. 判断整体趋势方向：上涨、下跌、震荡
2. 判断当前所处结构阶段
3. 识别是否已有明确的笔、线段、中枢
4. 给出高级别结论，作为后续低级别分析的约束

## 四、再看中周期

1. 在高级别结论下，判断中级别结构是否一致
2. 识别笔、线段、中枢的延续或破坏
3. 判断是否出现背驰迹象
4. 判断是否接近买卖点形成区

## 五、再看低周期

1. 检查低级别是否对高、中级别形成确认
2. 判断是否存在更清晰的入场、加仓、减仓、离场时机
3. 如果低级别与高级别冲突，以高级别为主

## 六、核心判断项

每次分析都要明确回答以下问题：

1. 当前趋势是什么
2. 当前结构是否完整
3. 是否存在中枢
4. 是否存在背驰
5. 是否存在可确认的买点或卖点
6. 如果没有信号，缺少什么条件

## 七、冲突处理规则

1. 高级别与低级别冲突时，以高级别为准
2. 低级别只用于确认、细化和择时
3. 信号不完整时，不强行下结论
4. 证据不足时，明确写"等待确认"

## 八、输出模板

分析结果统一按下面结构输出：

### 1. 标的与周期

- 标的：{代码/名称}
- 分析周期：{高级别/中级别/执行级别/精细级别}
- 时间范围：{起止时间}

### 2. 结构概述

- 高级别趋势：{上涨/下跌/震荡}
- 中级别结构：{描述}
- 低级别状态：{描述}

### 3. 关键证据

- 笔的构成：{描述}
- 线段状态：{描述}
- 中枢情况：{有无中枢/中枢位置/中枢级别}
- 结构形态：{描述}

### 4. 背驰判断

- 高级别背驰：{有/无/待定}
- 中级别背驰：{有/无/待定}
- 低级别背驰：{有/无/待定}
- 背驰力度：{描述}

### 5. 买卖点判断

- 买点类型：{一买/二买/三买/无}
- 卖点类型：{一卖/二卖/三卖/无}
- 买卖点位置：{价格区间}
- 确认条件：{描述}

### 6. 行动建议

- 当前操作：{观望/准备入场/入场/持有/减仓/离场}
- 仓位建议：{0%-100%}
- 下一步计划：{描述}

### 7. 风险与失效位

- 止损位：{价格}
- 止盈位：{价格}
- 失效条件：{描述}
- 风险提示：{描述}

## 九、质量检查

输出前检查：

1. 是否真的基于结构，而不是主观猜测
2. 是否区分了事实、判断、建议
3. 是否说明了不确定性
4. 是否给出了风险控制和失效条件
5. 是否遵循高周期优先原则
