# Chandelier Theory Analysis (缠论分析)

Comprehensive workflow for technical analysis using Chandelier Theory, focusing on multi-timeframe structure identification, divergence detection, and precise entry/exit signals.

## When to use (trigger phrases)

Use this skill immediately when the user asks any of:

- "analyze stock {code} with Chandelier Theory"
- "缠论分析 {标的}"
- "找买点/找卖点"
- "趋势判断"
- "多级别联动分析"
- "背驰判断"

## Quick Start

```
1. Confirm target: {stock code / ticker}
2. Confirm analysis goal: {trend / buy / sell / plan / multi-timeframe}
3. Confirm timeframe: {daily / 30min / 5min / 1min}
4. Confirm date range: {recent N days / specific period}
```

## Workflow

### 一、明确任务

1. **确认标的**: {股票代码 / 加密货币代号 / 期货合约}
2. **确认分析目标**: {看趋势 / 找买点 / 找卖点 / 做交易计划 / 做多级别联动判断}
3. **确认分析周期**: {日线 / 30分钟 / 5分钟 / 1分钟}
4. **确认时间范围**: {近N天 / 近N周 / 指定起止时间}

### 二、收集行情

1. 收集足够的K线数据，避免样本过短
2. 优先按高周期到低周期准备数据：
   - **高级别**: {如日线}
   - **中级别**: {如30分钟}
   - **执行级别**: {如5分钟}
   - **精细级别**: {如1分钟}

### 三、先看高周期

1. 判断整体趋势方向：上涨、下跌、震荡
2. 判断当前所处结构阶段
3. 识别是否已有明确的笔、线段、中枢
4. 给出高级别结论，作为后续低级别分析的约束

### 四、再看中周期

1. 在高级别结论下，判断中级别结构是否一致
2. 识别笔、线段、中枢的延续或破坏
3. 判断是否出现背驰迹象
4. 判断是否接近买卖点形成区

### 五、再看低周期

1. 检查低级别是否对高、中级别形成确认
2. 判断是否存在更清晰的入场、加仓、减仓、离场时机
3. 如果低级别与高级别冲突，以高级别为主

---

## 核心判断项

每次分析都要明确回答以下问题：

1. **当前趋势是什么**
2. **当前结构是否完整**
3. **是否存在中枢**
4. **是否存在背驰**
5. **是否存在可确认的买点或卖点**
6. **如果没有信号，缺少什么条件**

---

## 冲突处理规则

1. 高级别与低级别冲突时，以高级别为准
2. 低级别只用于确认、细化和择时
3. 信号不完整时，不强行下结论
4. 证据不足时，明确写"等待确认"

## 输出模板

分析结果统一按下面结构输出：

### 1. 标的与周期
- 标的：{代码/名称}
- 分析周期：{高级别 / 中级别 / 执行级别 / 精细级别}
- 时间范围：{起始日期 ~ 结束日期}

### 2. 结构概述
- 当前趋势：{上涨 / 下跌 / 震荡}
- 结构阶段：{形成中 / 延续中 / 即将完成 / 已破坏}
- 笔/线段状态：{方向 / 力度 / 延续性}

### 3. 关键证据
- 中枢识别：{是否存在 / 中枢区间 / 中枢类型}
- 线段划分：{数量 / 方向 / 相互关系}
- 关键点位：{压力位 / 支撑位 / 转折点}

### 4. 背驰判断
- 是否存在背驰：{是 / 否 / 待确认}
- 背驰类型：{趋势背驰 / 盘整背驰 / 线段背驰}
- 背驰力度：{轻微 / 中度 / 严重}
- 辅助验证：{MACD / 成交量 / 均线系统}

### 5. 买卖点判断
- 是否存在一买：{确认 / 待确认 / 无}
- 是否存在二买：{确认 / 待确认 / 无}
- 是否存在三买：{确认 / 待确认 / 无}
- 是否存在卖点：{确认 / 待确认 / 无}

### 6. 行动建议
- 操作方向：{买入 / 卖出 / 持有 / 观望}
- 仓位建议：{轻仓 / 半仓 / 重仓}
- 入场时机：{立即 / 等待回调 / 等待确认}

## 质量检查

输出前检查：

1. ✅ 是否真的基于结构，而不是主观猜测
2. ✅ 是否区分了事实、判断、建议
3. ✅ 是否说明了不确定性
4. ✅ 是否给出了风险控制和失效条件
5. ✅ 是否遵循高周期优先原则

---

## 术语速查

- **笔**: 相邻顶底分型之间的连线，至少包含5根K线
- **线段**: 由至少3笔构成的走势
- **中枢**: 至少3个连续次级别走势类型重叠部分
- **背驰**: 趋势力度减弱的表现，分趋势背驰和盘整背驰
- **一买**: 下跌趋势结束后的第一个买点
- **二买**: 一买后回调不创新低形成的买点
- **三买**: 突破中枢后回踩不进中枢形成的买点
