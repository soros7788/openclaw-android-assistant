# 缠论分析工作流模板

## 一、明确任务

1. **确认标的**：{标的代码/名称}
2. **确认分析目标**：{看趋势 / 找买点 / 找卖点 / 做交易计划 / 做多级别联动判断}
3. **确认分析周期**：{日线 / 30分钟 / 5分钟 / 1分钟}
4. **确认时间范围**：{近N天 / 近N周 / 指定起止时间}

## 二、收集行情

1. 收集足够的K线数据，避免样本过短
2. 优先按高周期到低周期准备数据：
   - **高级别**：{如日线}
   - **中级别**：{如30分钟}
   - **执行级别**：{如5分钟}
   - **精细级别**：{如1分钟}

## 三、先看高周期

1. 判断整体趋势方向：上涨、下跌、震荡
2. 判断当前所处结构阶段
3. 识别是否已有明确的笔、线段、中枢
4. 给出高级别结论，作为后续低级别分析的约束

## 四、再看中周期

1. 在高级别结论下，判断中级别结构是否一致
2. 识别笔、线段、中枢的延续或破坏
3. 判断是否出现背驰迹象
4. 判断是否接近买卖点形成区

## 五、再看低周期

1. 检查低级别是否对高、中级别形成确认
2. 判断是否存在更清晰的入场、加仓、减仓、离场时机
3. 如果低级别与高级别冲突，以高级别为主

## 六、核心判断项

每次分析都要明确回答以下问题：

1. **当前趋势是什么**
2. **当前结构是否完整**
3. **是否存在中枢**
4. **是否存在背驰**
5. **是否存在可确认的买点或卖点**
6. **如果没有信号，缺少什么条件**

## 七、冲突处理规则

1. **高级别与低级别冲突时，以高级别为准**
2. **低级别只用于确认、细化和择时**
3. **信号不完整时，不强行下结论**
4. **证据不足时，明确写"等待确认"**

## 八、输出模板

分析结果统一按下面结构输出：

1. **标的与周期**
2. **结构概述**
3. **关键证据**
4. **背驰判断**
5. **买卖点判断**
6. **行动建议**
7. **风险与失效位**

## 九、质量检查

输出前检查：

1. 是否真的基于结构，而不是主观猜测
2. 是否区分了事实、判断、建议
3. 是否说明了不确定性
4. 是否给出了风险控制和失效条件
5. 是否遵循高周期优先原则
